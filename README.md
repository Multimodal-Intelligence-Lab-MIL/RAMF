
# RAMF: Reasoning-Aware Multimodal Fusion for Hateful Video Detection

This repository provides the implementation of **RAMF (Reasoning-Aware Multimodal Fusion)**, a multimodal framework for hateful video detection.  

The implementation corresponds to the methodology described in the paper **“Reasoning-Aware Multimodal Fusion for Hateful Video Detection”**.

## 📌 Main Components

### Entry Scripts

* **`Code_MF/main.py`**
  Entry point for the **MF baseline**, following a traditional multimodal fusion pipeline.
* **`Code_RAMF/main.py`**
  Entry point for the **RAMF model**, integrating adversarial reasoning and hierarchical fusion.

### Core Modules

* **`Local_Global_Context_Fusion.py`**
  Implements LGCF, capturing both local salient cues and global temporal context.
* **`Semantic_Cross_Attention.py`**
  Implements SCA with cross-head and structural mixing convolutions for fine-grained multimodal interaction.
* **`MLP_Projection.py`**
  Projects modality-specific features into a unified embedding space.
* **`RAMF.py`**
  Defines the overall RAMF architecture and forward logic.

### Training

* **`trainner.py`**
  Handles training loops, loss computation, optimisation, validation, and evaluation.

## 🧠 LLM / VLM Reasoning Module

Located in **`Code_LLM_Reasoning/`**, this part is responsible for generating and processing reasoning text using large vision-language models (e.g. Qwen).

The adversarial reasoning pipeline includes:

1. **Objective Description**
2. **Hate-Assumed Inference**
3. **Non-Hate-Assumed Inference**

Generated texts are filtered and encoded before being fused with traditional modalities.

---

## 🔍 Feature Extraction Pipeline (As Described in the Paper)

This section explains **how features are extracted** for each modality, following the methodology in the paper.

### 1. Text Modality (T)

* Speech is transcribed using **OpenAI Whisper**.
* Transcripts are encoded using:

  * **BERT / mBERT**, or
  * **HateXplain (HXP)**.
* Output:

  * 768-dimensional embeddings.
  * Sequence length is truncated or zero-padded to **100 tokens**.
* These embeddings are later projected via an MLP to a unified dimension.

---

### 2. Reasoning Texts (TO, TH, TN)

Generated by a **Vision-Language Model (VLM)** through adversarial prompting:

* **TO**: Objective description
* **TH**: Hate-assumed inference
* **TN**: Non-hate-assumed inference

Processing steps:

* Encoded using the same text encoder as transcripts (BERT / HXP).
* Passed through an **MLP projection** with hidden sizes `{512, 256}` to align with other modalities.

---

### 3. Audio Modality (A)

Two complementary audio representations are used:

1. **MFCC Features**

   * Audio resampled to **16 kHz**.
   * Extract **40-dimensional MFCC** features.
   * Temporal sequences are downsampled or padded to a fixed length.

2. **CLAP Features**

   * Audio resampled to **48 kHz**.
   * Extract **512-dimensional semantic embeddings** using pretrained **CLAP**.
   * Provides higher-level audio semantics.

---

### 4. Visual Modality (V)

Video frames are sampled uniformly.

Two visual encoders are used:

1. **ViT / ViViT**

   * Extract **768-dimensional frame-level embeddings**.
2. **CLIP**

   * Extract **512-dimensional semantic embeddings**.

Padding:

* Black frames are used if the video is shorter than the required length.

---

### 5. Unified Feature Projection

All modality-specific features are passed through an **MLP projection layer** to:

* Unify dimensionality.
* Reduce modality imbalance.
* Facilitate subsequent fusion.

## 🔗 Multimodal Fusion

### Local-Global Context Fusion (LGCF)

* Combines:

  * **Local Temporal Channel** (1D convolution + max pooling)
  * **Global Temporal Channel** (adaptive average pooling)
* A learnable gate adaptively fuses local and global features.

### Semantic Cross Attention (SCA)

* Introduces:

  * **Cross-Head Convolution (CHC)** for inter-head communication.
  * **Structural Mixing Convolution (SMC)** for robust semantic alignment.
* Used hierarchically:

  1. Fuse `{Text, Audio, Video, Objective Description}`
  2. Fuse the result with `{Hate-Assumed, Non-Hate-Assumed}` reasoning

## 📊 Datasets

Five-fold cross-validation datasets:

* **HateMM**

  * `five_folds_HateMM.pickle`
* **MultiHateClip (MHC)**

  * `five_fold_MHC.pkl`
  * `five_fold_MHC_E.pkl`

Each fold has a mutually exclusive test set to ensure generalisation.
